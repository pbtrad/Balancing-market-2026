# Energy Decision Engine

Foundation scaffold for an I-SEM energy decision engine focused on:

- short-term imbalance forecasting,
- price/spike forecasting,
- constrained dispatch recommendations.

## Current Scope

This repository currently implements **Phase 1 (Foundation)**:

- project structure scaffold,
- initial domain models and constraint logic,
- isolated I-SEM rule module,
- baseline previous-day model,
- unit tests for foundational behavior.
